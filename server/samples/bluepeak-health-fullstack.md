# BluePeak Health (fictional sample) - Full Stack Engineer (React + Node.js)

Location: Remote (India time zone overlap with UK required). Experience: 2-4 years. Salary: 10 to 16 LPA.

## About us
BluePeak Health runs appointment booking and telemedicine software for 1,200 clinics across the UK and India.

## Responsibilities
- Build features end to end with React, TypeScript and Next.js on the frontend and Node.js (NestJS) on the backend.
- Own PostgreSQL data models and MongoDB collections for audit events.
- Build real-time appointment updates with WebSockets.
- Add AI features: a retrieval-augmented assistant that answers clinic staff questions from internal policy documents.
- Keep the platform secure and reliable: rate limiting, role-based access, retries with backoff and monitoring.

## Must have
- Strong React and Node.js experience with TypeScript.
- SQL and NoSQL databases. Writing tests (Jest or Vitest).
- Clear written English for async remote work.

## Good to have
- Experience with embeddings, vector search (pgvector) or LLM APIs.
- AWS (ECS, SQS, RDS) and CI/CD with GitHub Actions.

## Benefits
Fully remote, home office budget, health insurance, 24 days of paid leave.
