# Northwind Learning (fictional sample) - PHP Laravel Developer

Location: Ahmedabad, India (on-site, 5 days a week). Experience: 1-3 years. CTC: 4.5 to 6.5 LPA.

## About the role
Northwind Learning builds a learning management system used by 300 colleges. You will build and maintain
Laravel modules for course enrolment, fee payments and exam results.

## What you will do
- Build REST APIs in Laravel 11 with form request validation and Sanctum authentication.
- Design MySQL schemas, write migrations and optimise slow queries with indexes.
- Move heavy work such as report generation and bulk emails to Laravel queues backed by Redis.
- Integrate the Razorpay payment gateway, including webhook handling.
- Write PHPUnit feature tests for every new endpoint.

## Requirements
- 1+ year of professional Laravel experience. Strong PHP 8 and OOP fundamentals.
- Good MySQL skills: joins, indexes, transactions.
- Git, code reviews, and comfort deploying with Docker.

## Nice to have
- Vue.js or React for admin panels. Experience with AWS S3 and SES.

## Notice period
We prefer candidates who can join within 30 days. Immediate joiners are a plus.
