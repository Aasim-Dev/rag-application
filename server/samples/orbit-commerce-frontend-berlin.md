# Orbit Commerce (fictional sample) - Frontend Developer (Vue / React), Berlin

Location: Berlin, Germany (hybrid, 2 office days). Relocation support and EU Blue Card visa sponsorship available.
Experience: 1-3 years. Salary: 52,000 to 62,000 EUR per year.

## The team
Orbit Commerce builds a headless e-commerce platform used by 400 online shops in the DACH region.

## Your work
- Build storefront and checkout features in Vue 3 and Nuxt, plus internal tools in React.
- Work with our Shopware and Laravel backend team on API contracts.
- Improve Core Web Vitals and accessibility (WCAG 2.1 AA).
- Write component tests and end-to-end tests with Playwright.

## What we look for
- Solid JavaScript and TypeScript, HTML and CSS.
- Experience with a modern framework: Vue or React.
- Good English. German is a plus, not a requirement.

## Process
A 30-minute intro call, a take-home task (about 3 hours), and a final technical interview.
